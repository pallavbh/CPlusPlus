# FunctionVirtual and Polymorphism

This folder includes examples of virtual functions, overriding, and polymorphism in C++. These advanced concepts enable flexible and extensible object-oriented design.

## Files

| File | Description |
|---|---|
| functionOverriding.cpp | Basic example of function overriding in inheritance hierarchy |
| functionOverrridingPtr.cpp | Function overriding demonstrated using base class pointers |
| inheritancePolymorphismImplementation.cpp | Complete demonstration of inheritance and polymorphic behavior |
| pureVirtualFunction.cpp | Example of abstract classes using pure virtual functions |
| pureVirtualFunction1.cpp | Additional pure virtual function example with multiple implementations |
| virtualFunctionOverriding.cpp | Comprehensive demonstration of virtual function overriding and dynamic polymorphism |

## Concepts Covered

- Virtual functions and dynamic dispatch
- Function overriding in derived classes
- Abstract classes using pure virtual functions
- Polymorphic behavior through base class pointers/references
