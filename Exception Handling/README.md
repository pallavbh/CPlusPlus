# Exception Handling

Examples of C++ exception handling using `throw`, `try`, and `catch`.

## Files

- `Example1.cpp` — basic exception handling
- `MultipleCatchBlock.cpp` — catching different exception types
- `TryCatch.cpp` — runtime error handling

## Concepts

- Throwing exceptions with `throw`
- Catching exceptions with `try` and `catch`
- Multiple `catch` blocks
- Standard exceptions like `std::invalid_argument` and `std::out_of_range`

## Run

```bash
g++ Example1.cpp -o Example1.exe
.\Example1.exe
```
