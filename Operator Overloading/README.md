# Operator Overloading

This folder demonstrates operator overloading techniques in C++ for user-defined types. Operator overloading allows custom classes to behave like built-in types and enhances code readability and intuitiveness.

## Files

| File | Description |
|---|---|
| operatorOverloading.cpp | Demonstrates basic overloading of operators for user-defined types |
| operatorOverloading_1.cpp | Additional operator overloading example using complex numbers |
| operatorOverloadingUnary_BInary.cpp | Example of unary and binary operator overloading |
| operatorOverloadingUnary_BInary2.cpp | Additional unary and binary operator overloading example |
| operatorOverloadingUsingConstructor.cpp | Operator overloading using constructors for type conversion |
| classToBasicTypeConversion.cpp | Conversion from a class type to a basic type using conversion operators |
| functionOverloading.cpp | Example of function or operator overloading in the folder |

## Concepts Covered

- Overloading unary operators (++, --, !, etc.)
- Overloading binary operators (+, -, *, ==, <, etc.)
- Conversion operators for type casting
- Friend functions for operator overloading
- Best practices in operator overloading
