# Operator Overloading

This folder demonstrates operator overloading techniques in C++ for user-defined types.

## Files

| File | Description |
|---|---|
| classToBasicTypeConversion.cpp | Conversion from a class type to a basic type |
| functionOverloading.cpp | Example of function or operator overloading in the folder |
| operatorOverloading.cpp | Demonstrates overloading operators for user-defined types |
| operatorOverloadingUsingConstructor.cpp | Operator overloading using constructors |
| operatorOverloading_1.cpp | Additional operator overloading example using complex numbers |
| operatorOverloadingUnary_BInary.cpp | Example of unary and binary operator overloading |
| operatorOverloadingUnary_BInary2.cpp | Additional unary and binary operator overloading example |
