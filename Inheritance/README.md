# Inheritance

This folder contains comprehensive examples of different inheritance types and related ambiguity scenarios in C++. Inheritance is a core OOP mechanism for code reuse and establishing hierarchical relationships between classes.

## Files

| File | Description |
|---|---|
| inheritance.cpp | Basic inheritance example |
| inheritance1.cpp | Additional inheritance example |
| singleInheritance.cpp | Single inheritance example (most common inheritance type) |
| multiLevel_Inheritance.cpp | Example of multilevel inheritance (grandparent to parent to child) |
| multiLevel_Inheritance1.cpp | Additional multilevel inheritance example |
| multiple_Inheritance.cpp | Example of multiple inheritance (inheriting from multiple classes) |
| public_Inheritance.cpp | Example demonstrating public inheritance and access control |
| hierarchical_Inheritance.cpp | Example of hierarchical inheritance (one parent, multiple children) |
| hybrid_Inheritance.cpp | Example combining multiple inheritance types |
| diamondAmbiguity1.cpp | Demonstrates ambiguity in diamond inheritance pattern |
| diamondMultipathAmbiguity.cpp | Example of diamond/multipath ambiguity resolution |
| multipathAmbiguity.cpp | Another multipath inheritance ambiguity example |

## Concepts Covered

- Single inheritance
- Multilevel inheritance (3+ levels)
- Multiple inheritance
- Hierarchical inheritance
- Hybrid inheritance
- Diamond problem and ambiguity resolution
- Virtual base classes for ambiguity handling
