# Inheritance

This folder contains examples of inheritance types and related ambiguity scenarios in C++.

## Files

| File | Description |
|---|---|
| inheritance.cpp | Basic inheritance example |
| inheritance1.cpp | Additional inheritance example |
| singleInheritance.cpp | Single inheritance example |
| multiLevel_Inheritance.cpp | Example of multilevel inheritance |
| multiLevel_Inheritance1.cpp | Additional multilevel inheritance example |
| multiple_Inheritance.cpp | Example of multiple inheritance |
| public_Inheritance.cpp | Example demonstrating public inheritance |
| hierarchical_Inheritance.cpp | Example of hierarchical inheritance |
| hybrid_Inheritance.cpp | Example combining multiple inheritance types |
| diamondAmbiguity1.cpp | Demonstrates ambiguity in diamond inheritance |
| diamondMultipathAmbiguity.cpp | Example of diamond/multipath ambiguity |
| multipathAmbiguity.cpp | Another multipath inheritance ambiguity example |
