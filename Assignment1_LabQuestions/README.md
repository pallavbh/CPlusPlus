# Assignment1_LabQuestions

This folder contains the first set of comprehensive lab exercises covering C++ OOP and core language concepts. These labs progress from basic concepts like arrays and pointers to advanced topics like inheritance, constructors, destructors, and operator overloading.

## Files

| File | Description |
|---|---|
| lab1_ArrayAndPointer.cpp | Array and pointer basics |
| lab2_NewAndDelete.cpp | Dynamic memory allocation using new and delete |
| lab3_ConstAndEnum.cpp | Use of const and enum for type safety and constants |
| lab4_FunctionOverloadingAndDefaultArguments.cpp | Function overloading and default arguments |
| lab5_InlineFunction.cpp | Inline function example and optimization |
| lab6_ClassAndAccessSpecifier.cpp | Class declaration and access specifiers (public, private, protected) |
| lab7_NestingOfMemberFunction.cpp | Member functions calling one another |
| lab8_ArrayOfObjectAndThisPointer.cpp | Arrays of objects and the this pointer |
| lab9_PassingObjectsByReference.cpp | Passing objects by reference |
| lab10_ReturningObject.cpp | Returning objects from functions |
| lab11_StaticDataMemberAndFunction.cpp | Static data members and static member functions |
| lab12_FriendFunction.cpp | Friend function example and access control |
| lab13_FriendClass.cpp | Friend class example |
| lab14_StringClassBasic.cpp | Basic string class example |
| lab15_CopyConstructorAndDeepCopy.cpp | Copy constructor and deep copy semantics |
| lab16_FriendFunctionForOperatorOverloading.cpp | Friend function used for operator overloading |
| lab17_ReturningObjectByValueVsRefrence.cpp | Returning objects by value versus by reference |
| lab18_DefaultAndParameterizedConstructor.cpp | Default and parameterized constructors |
| lab19_CopyConstructor.cpp | Copy constructor example and behavior |
| lab20-OverloadedConstructors.cpp | Multiple overloaded constructors |
| lab21_Destructor.cpp | Destructor example and resource cleanup |
| lab22_ConstructorInitializerList.cpp | Constructor initializer lists for member initialization |
| lab23_ConstructionAndDestructionOrdering.cpp | Constructor/destructor order demonstration in inheritance |
| lab24_ComplexClassWithConstructorsAndDestructor.cpp | Complex class using constructors and destructor together |
| lab25_SingletonPatternWithStaticMembers.cpp | Singleton pattern using static members |

## Purpose

These labs build foundational understanding of C++ OOP, memory management, and class design patterns.
