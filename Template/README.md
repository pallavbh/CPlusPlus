# Template

This folder contains basic C++ template programming examples for learning generic programming.

## Files

| File | Description |
|---|---|
| Template1.cpp | Simple function template example |
| Template2.cpp | Another template example using generic types |
| TemplateOverloading.cpp | Example of template function overloading |
| TwoParameterTemplate.cpp | Template with two parameters |

## Purpose

Templates allow the same code to work with different data types without rewriting logic. They enable generic programming and are fundamental to the Standard Template Library (STL).
